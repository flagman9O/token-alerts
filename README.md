# Token Alerts

Телеграм-бот, который следит за токенами на Solana, BSC, Base и RobinHood и
пишет вам, когда токен одновременно проходит все ваши пороги: капитализация,
объём за последнюю минуту и накопленные комиссии. Все величины считаются
**по всем пулам токена**, а не по одному — иначе картина искажается в разы.

Бот только уведомляет. Ключей от кошелька в нём нет и торговать он не умеет.

## Откуда данные

Официальный [GMGN OpenAPI](https://docs.gmgn.ai/): капитализация, минутный
объём, накопленные комиссии по всем пулам, риск-метрики (доля топ-10
держателей, признаки накрутки объёма, доля бандлеров), число смарт-мани и
KOL-кошельков — всё в одном ответе, без сборки из нескольких источников.
Ссылка на bubblemaps в каждом алерте — для Solana, BSC, Base, Ethereum и
RobinHood.

Капитализация и объём фильтруются **на стороне gmgn**: один запрос на сеть
возвращает уже отсортированный и отфильтрованный список. Комиссии по каждому
кандидату из этого списка добираются отдельным запросом — их обычно
несколько штук за проход, а не тысячи.

Сводку «что за мем» пишет Groq по описанию токена и содержимому его аккаунта
в Twitter (читается через markdown.new, без ключа и без входа).

## Комиссии в валюте сети

Комиссии считаются в нативной монете каждой сети (SOL, BNB, ETH), поэтому
порог хранится **в долларах** и на лету переводится в нужную валюту по курсу
Binance — так одно число работает одинаково на всех сетях.

## Требования

- Python 3.10+
- Linux или macOS
- телеграм-бот от [@BotFather](https://t.me/BotFather)
- API-ключ [GMGN](https://gmgn.ai/ai) (бесплатный, только чтение — торговлю
  включать не нужно)

## Установка

```bash
git clone https://github.com/USERNAME/token-alerts.git
cd token-alerts
./install.sh
```

Затем положите ключи в `~/.token-alerts/` (или задайте переменными окружения):

```bash
mkdir -p ~/.token-alerts && chmod 700 ~/.token-alerts
echo "ТОКЕН_ОТ_BOTFATHER" > ~/.token-alerts/bot-token
echo "ВАШ_TELEGRAM_ID"    > ~/.token-alerts/owner-id
echo "КЛЮЧ_GMGN"          > ~/.token-alerts/gmgn-api-key
echo "КЛЮЧ_GROQ"          > ~/.token-alerts/groq-key   # необязательно
chmod 600 ~/.token-alerts/*
```

Свой numeric id можно узнать у [@userinfobot](https://t.me/userinfobot). Ключ
GMGN получается на [gmgn.ai/ai](https://gmgn.ai/ai) — там же генерируется пара
ключей для подписи; она нужна только для торговли, этому боту хватает самого
API-ключа. Ключ Groq нужен только для сводок о мемах, без него бот работает и
просто их не показывает.

Переменные окружения `TG_BOT_TOKEN`, `TG_OWNER_ID`, `GMGN_API_KEY`,
`GROQ_API_KEY` и `TOKEN_ALERTS_HOME` перекрывают файлы.

Запуск:

```bash
./.venv/bin/python bot.py
```

Автозапуск — команды печатает `install.sh` после установки.

## Настройки

`/settings` открывает меню на кнопках: выбор сети → пороги этой сети
(капитализация, объём за минуту, комиссии — с переключателем валюты SOL/BNB/ETH
или доллары, — возраст, вкл/выкл алертов, вкл/выкл сводки о токене,
риск-фильтр, «проверить сейчас» для мгновенной проверки без ожидания цикла) →
общие параметры (режим watch/live, ликвидность, повтор алерта). У чисел без
готового варианта — «✏️ Своё значение», бот попросит прислать число
сообщением.

Каждая сеть настраивается независимо, поэтому и работает у неё всё, что ниже,
по-своему: свои пороги, свой флаг «алерты вкл/выкл», своя сводка о токене.

Под каждым алертом — кнопки «🔇 1ч / 4ч / 24ч / навсегда»: заглушают алерты
именно по этому токену, не трогая пороги сети. «Навсегда» переносит токен в
список «🗑 Удалённые» в настройках его сети — оттуда можно вернуть кнопкой
«♻️ Вернуть». Временные мьюты нигде не перечисляются и снимаются сами по
истечении срока.

Те же настройки доступны текстом, для скриптования и быстрых правок:

| Команда | Что делает |
|---|---|
| `/status` | текущие пороги по всем сетям и статистика |
| `/set ключ значение` | сменить порог: общий (`realert_min`, `liq_min`) или сетевой вида `sol.mc_min` |
| `/chains` | список сетей и их состояние |
| `/chains sol off` | выключить алерты по сети (`on` — включить) |
| `/mode watch` | тихий режим: копить и слать сводку раз в сутки |
| `/mode live` | присылать находки сразу |
| `/last` | находки за сутки |

Сетевые ключи для `/set`: `mc_min`, `vol1m_min`, `fees_min` (только в
долларах — валюту ввода меняйте в `/settings`), `max_age_h` (0 — без
ограничения). Общие: `realert_min` (в минутах), `liq_min`.

Значения по умолчанию на каждую включённую сеть: капитализация от $200 000,
объём за минуту от $50 000, комиссии от $2 400 (≈ 25 SOL), возраст без
ограничения, повтор по тому же токену не чаще получаса. Доступные сети:
`sol`, `bsc`, `base`, `robinhood` включены сразу, `eth` — по запросу.

## Режим наблюдения

Бот стартует в режиме `watch`: находки пишутся в базу, но в чат не летят, а раз
в сутки приходит сводка. Это сделано, чтобы настроить пороги на реальных
данных и не получить поток сообщений с первого дня. Когда цифры устроят —
`/mode live`.

## Ограничения

**Есть задержка.** Проход по сетям — раз в 30 секунд, уведомление приходит
почти сразу после того, как токен попал в топ по объёму на стороне gmgn.
Для реакции быстрее секунд нужен платный поток сделок, здесь он не
используется.

**Сводка о меме зависит от того, что есть в сети.** Если у токена нет описания
и нет активного твиттера, бот честно ничего не покажет.

## Данные

Всё в `alerts.db` рядом с кодом: история находок и пороги. Ни база, ни ключи
в git не попадают.
