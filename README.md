# Token Alerts

Телеграм-бот, который следит за токенами Solana и пишет вам, когда токен
одновременно проходит все ваши пороги: капитализация, объём за последнюю
минуту и накопленные комиссии. Все величины считаются **по всем пулам токена**,
а не по одному — иначе картина искажается в разы.

Бот только уведомляет. Ключей от кошелька в нём нет и торговать он не умеет.

## Как он считает

**Объём за минуту.** Бесплатные API отдают минимум пятиминутное окно. Но для
токена моложе суток окно `h24` покрывает всю его жизнь, поэтому разница между
двумя замерами — это ровно то, что наторговали за интервал. Бот опрашивает
список наблюдения раз в минуту и берёт дельту.

**Комиссии за всё время.** Считаются как оборот × 0.25% ÷ цена SOL. Ставка
выведена сверкой с реальными данными: на токене возрастом 16 часов расчёт дал
210 SOL против 200 SOL, показанных биржевым терминалом, — отклонение около 5%.

**Капитализация и ликвидность.** Суммируются по всем пулам через DexScreener.

## Откуда данные

Всё бесплатно и без ключей:

| Источник | Что даёт |
|---|---|
| DexScreener | капитализация, объёмы, ликвидность по всем пулам |
| PumpPortal (websocket) | поток новых токенов и миграций |
| GeckoTerminal | новые пулы остальных площадок Solana |
| pump.fun | описание токена, твиттер, сайт |
| Groq | краткая сводка «что за мем», опционально |

## Как устроен отбор

Перебрать все токены сети бесплатные API не позволяют, поэтому бот держит
скользящий список наблюдения: всё, что появилось за последние сутки. Проверка
идёт в два этапа, чтобы уложиться в лимиты:

1. дешёвый скрининг капитализации — по тридцать токенов за один запрос;
2. подробный разбор по всем пулам — только для тех, кто прошёл первый этап.

## Требования

- Python 3.10+
- Linux или macOS
- телеграм-бот от [@BotFather](https://t.me/BotFather)

## Установка

```bash
git clone https://github.com/USERNAME/token-alerts.git
cd token-alerts
./install.sh
```

Затем положите ключи в `~/.token-alerts/` (или задайте переменными окружения):

```bash
mkdir -p ~/.token-alerts && chmod 700 ~/.token-alerts
echo "ТОКЕН_ОТ_BOTFATHER" > ~/.token-alerts/bot-token
echo "ВАШ_TELEGRAM_ID"    > ~/.token-alerts/owner-id
echo "КЛЮЧ_GROQ"          > ~/.token-alerts/groq-key   # необязательно
chmod 600 ~/.token-alerts/*
```

Свой numeric id можно узнать у [@userinfobot](https://t.me/userinfobot). Ключ
Groq нужен только для сводок о мемах, без него бот работает и просто их не
показывает.

Переменные окружения `TG_BOT_TOKEN`, `TG_OWNER_ID`, `GROQ_API_KEY` и
`TOKEN_ALERTS_HOME` перекрывают файлы.

Запуск:

```bash
./.venv/bin/python bot.py
```

Автозапуск — команды печатает `install.sh` после установки.

## Команды в чате

| Команда | Что делает |
|---|---|
| `/status` | текущие пороги и статистика |
| `/set ключ значение` | сменить порог на лету |
| `/mode watch` | тихий режим: копить и слать сводку раз в сутки |
| `/mode live` | присылать находки сразу |
| `/last` | находки за сутки |

Ключи порогов: `mc_min`, `vol1m_min`, `fees_min`, `liq_min`, `max_age_h`,
`realert_h`.

Значения по умолчанию: капитализация от $200 000, объём за минуту от $50 000,
комиссии от 25 SOL, возраст до 24 часов, повтор по тому же токену не чаще
шести часов.

## Режим наблюдения

Бот стартует в режиме `watch`: находки пишутся в базу, но в чат не летят, а раз
в сутки приходит сводка. Это сделано, чтобы настроить пороги на реальных
данных и не получить поток сообщений с первого дня. Когда цифры устроят —
`/mode live`.

## Ограничения

**Комиссии точны только для молодых токенов.** Расчёт опирается на суточное
окно, поэтому для токена старше суток он покажет комиссии за последний день, а
не за всё время. Бот по умолчанию и смотрит только на токены моложе 24 часов,
так что в штатном режиме это не мешает.

**Есть задержка.** Опрос раз в минуту плюс задержка обновления DexScreener —
уведомление приходит через 30–90 секунд после того, как порог реально пробит.
Для мгновенной реакции нужен платный поток сделок, здесь он не используется.

**Сводка о меме зависит от описания.** Его пишет создатель токена; если там
пусто или бессмыслица, бот честно ничего не покажет.

## Данные

Всё в `alerts.db` рядом с кодом: список наблюдения, история находок и пороги.
Ни база, ни ключи в git не попадают.
