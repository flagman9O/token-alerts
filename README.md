# Token Alerts — радар для заработка на пулах ликвидности сразу в нескольких сетях

> Телеграм-бот, который следит за токенами сразу в четырёх сетях — Solana, BSC, Base и
> RobinHood — и пишет вам, как только токен одновременно проходит все ваши пороги:
> капитализацию, объём за последнюю минуту и накопленные комиссии. Сделан для того,
> чтобы замечать возможности заработка на комиссиях свежих пулов ликвидности раньше толпы.

## 😖 Какую проблему решает

Зарабатывать на ранних комиссиях в свежих мем-пулах означает следить сразу за четырьмя
сетями в поисках токена, который только что прошёл порог капитализации, дал всплеск
объёма и при этом уже реально накопил комиссии — а не просто появился в списке. Делать
это руками по нескольким сайтам слишком медленно: нужное окно закрывается раньше, чем
вы это заметите. Бот берёт на себя слежение — решение, заходить или нет, остаётся за вами.

## 🔄 Принцип работы

Каждые 30 секунд бот проходит по каждой включённой сети: сначала запрашивает у GMGN
список токенов, уже отфильтрованный на их стороне по капитализации и объёму за минуту, —
это кандидаты, прошедшие два порога из трёх. Для каждого кандидата отдельным запросом
забирает накопленные комиссии по всем его пулам и проверяет третий порог. Если включена
сводка — Groq по описанию токена и его аккаунту в Twitter пишет пару предложений о том,
что это за мем. Дальше в Telegram уходит карточка с метриками, флагами риска и ссылками
(gmgn, bubblemaps, twitter) — под ней кнопки, которыми можно заглушить этот токен на 1,
4, 24 часа или навсегда (навсегда — токен уходит в список «Удалённые»). В тихом режиме
(watch) находки просто пишутся в базу, и раз в сутки в 10:00 по времени сервера приходит
общая сводка; в режиме live каждая находка отправляется сразу.

## 🏗 Архитектура

```
GMGN OpenAPI → scan_chain() (раз в 30 секунд на сеть; кандидаты уже отфильтрованы
               по капитализации и объёму)
             → token/info (накопленные комиссии по всем пулам кандидата)
             → Groq + Twitter (сводка о меме, опционально)
             → Telegram: карточка алерта + кнопки мьюта

Telegram (постоянный опрос) ↔ владелец: команды и меню /settings

Сквозное: SQLite (настройки, история алертов, мьюты) · кэш курса Binance (перевод
порога по комиссиям в валюту) · версионные миграции схемы базы · ограничитель скорости
запросов (держит бота под лимитом gmgn в 20 запросов/с)
```

## ✨ Возможности

- **Четыре сети, каждая настраивается отдельно** — Solana, BSC, Base, RobinHood включены
  сразу; Ethereum доступен, но выключен, пока не включите сами.
- **Учёт по всем пулам** для капитализации, объёма и комиссий — без перекоса по одному пулу.
- **Фильтрация на стороне gmgn** — пороги по капитализации и объёму применяет сам gmgn;
  бот тратит дополнительные запросы только на кандидатов, уже прошедших оба порога.
- **Порог по комиссиям — в удобной вам валюте**: в нативной монете (SOL/BNB/ETH) или в
  долларах, с курсом Binance в реальном времени под капотом — одно число работает
  одинаково на любой сети.
- **Фильтр риска** — необязательный, для каждой сети отдельно: пропускает токены с
  высоким риском рага, признаками накрутки объёма или большой долей бандлеров, используя
  собственные метрики риска gmgn — без дополнительных запросов.
- **Заглушить токен прямо с алерта** — кнопки «🔇 1ч / 4ч / 24ч / навсегда» отключают
  алерты именно по этому токену, не трогая пороги сети. «Навсегда» переносит его в список
  **«Удалённые»** в настройках этой сети — оттуда можно вернуть одним нажатием.
- **Задержка перед повтором** — готовые варианты 5/10/15/30/60 минут, чтобы один и тот же
  токен не повторялся при каждом проходе.
- **Режимы watch и live** — старт в тихом режиме (одна сводка в сутки), чтобы
  откалибровать пороги на реальных данных до самого первого настоящего алерта.
- **«Проверить сейчас»** по каждой сети прямо из меню настроек — не дожидаясь следующего
  прохода.
- **Кликабельные ссылки** в каждом алерте — gmgn, BubbleMaps (sol/bsc/base/eth/robinhood),
  Twitter, сайт, Telegram, адрес контракта в одно касание.

## ⚙️ Настройка — «/settings»

```
/settings
 └─ выбор сети (или «Общие») ──▶ экран сети
       ├─ алерты вкл/выкл
       ├─ капитализация ▸ готовые варианты или своё число
       ├─ объём за минуту ▸ готовые варианты или своё число
       ├─ комиссии ▸ варианты в нативной монете или в долларах, переключатель валюты
       ├─ возраст ▸ варианты или своё число (0 — без ограничения)
       ├─ сводка о токене вкл/выкл
       ├─ риск-фильтр вкл/выкл
       ├─ 🔍 проверить сейчас
       └─ 🗑 Удалённые (N) ▸ токены, заглушённые «навсегда», возврат в одно касание
 └─ «Общие» ──▶ режим (watch/live), задержка перед повтором, мин. ликвидность
```

Каждая сеть настраивается независимо — свои пороги, свой переключатель «алерты
вкл/выкл», своя сводка о токене. Те же настройки доступны текстовыми командами — для
скриптов и быстрых правок без открытия меню:

| Команда | Что делает |
|---|---|
| `/status` | текущие пороги по всем сетям и статистика |
| `/set ключ значение` | сменить порог: общий (`realert_min`, `liq_min`) или сетевой вида `sol.mc_min` |
| `/chains` | список сетей и их состояние |
| `/chains sol off` | выключить алерты по сети (`on` — включить) |
| `/mode watch` | тихий режим: копить и слать сводку раз в сутки |
| `/mode live` | присылать находки сразу |
| `/last` | находки за сутки |

Значения по умолчанию на каждую включённую сеть: капитализация от `$200 000`, объём за
минуту от `$50 000`, накопленные комиссии от `$2 400` (≈ 25 SOL), без ограничения по
возрасту, повтор по тому же токену не чаще раза в полчаса.

## 🤖 Сводки о токене (необязательно, через Groq)

Если включено для сети, каждый алерт получает сводку «что за мем» на 2-3 предложения —
её пишет Groq (`openai/gpt-oss-120b`) по описанию токена и содержимому его аккаунта в
Twitter (читается через markdown.new, без ключа и без входа). Если у токена нет ни
описания, ни активного твиттера, бот честно так и скажет, а не выдумает историю.
Полностью необязательно — оставьте ключ Groq пустым при установке, и бот будет работать
без сводок.

## 🛡 Меры безопасности

- **Кошелька нет вообще.** Бот только читает открытые рыночные данные — у него нет
  приватного ключа, и он не может совершить сделку; это заложено в саму конструкцию, а
  не выключается флажком, который можно случайно перепутать.
- **Ключ GMGN только на чтение.** Установка генерирует ключевую пару Ed25519
  исключительно ради формы создания ключа на стороне gmgn; приватная половина никогда не
  записывается на диск и не используется — подпись нужна только для торговых запросов,
  которые этот бот никогда не вызывает.
- **Доступ только у владельца.** Каждое сообщение и нажатие кнопки сверяется с одним
  числовым `chat_id`; кто угодно ещё, кто найдёт бота, просто не получит ответа — ни
  данных, ни алертов ему не уйдёт.
- **Тихий режим по умолчанию.** В чат ничего не летит, пока вы сами не переключите
  `/mode live`.

## 🚀 Установка за несколько минут — без помощника рядом

Скрипт установки сам спрашивает каждый ключ по очереди и говорит, что именно нажать и
куда сходить за каждым из них.

```bash
git clone https://github.com/flagman9O/token-alerts.git
cd token-alerts
sudo apt install -y python3-venv   # на части образов Debian/Ubuntu venv — отдельный пакет
./install.sh
```

Спросит по порядку:

1. **Токен бота.** Подскажет написать [@BotFather](https://t.me/BotFather) → `/newbot`,
   а затем сам проверит присланный токен через Telegram.
2. **Ваш Telegram ID.** Попросит один раз написать что угодно новому боту и сам подхватит
   ваш числовой ID из этого сообщения — искать вручную не придётся.
3. **Ключ GMGN.** Сгенерирует ключевую пару локально и выдаст готовую ссылку на gmgn.ai
   с уже вставленным публичным ключом — останется включить «Enable Reading», нажать
   Create и вставить ключ обратно. Перед переходом по ссылке нужен свой аккаунт на
   gmgn.ai и вход в него в том же браузере. Приватный ключ никогда не сохраняется —
   этому боту он не нужен.
4. **Ключ Groq**, необязательно — включает сводки о мемах. Оставьте пустым, чтобы
   пропустить, бот и без него работает нормально.

Дальше сам поставит виртуальное окружение и подготовит файл systemd-службы, команды для
автозапуска покажет в конце. Если запустить `install.sh` повторно (например, после
`git pull`) — предложит оставить уже сохранённые ключи вместо того, чтобы спрашивать
заново.

Переменные окружения `TG_BOT_TOKEN`, `TG_OWNER_ID`, `GMGN_API_KEY`, `GROQ_API_KEY` и
`TOKEN_ALERTS_HOME` перекрывают файлы на диске — пригодится для Docker или CI, где
`install.sh` не запускают вручную.

Запуск без systemd:

```bash
./.venv/bin/python bot.py
```

## 🖥 Какой сервер брать

Бот лёгкий — это asyncio-скрипт, который только делает небольшие исходящие запросы за
JSON и пишет в SQLite. Никакого веб-сервера, никаких тяжёлых вычислений. Достаточный
минимум с запасом:

- **1 ядро процессора** — время уходит на ожидание сети, а не на счёт.
- **512 МБ — 1 ГБ оперативной памяти** — реальный расход держится в районе 50–150 МБ,
  остальное — запас под операционную систему и виртуальное окружение. На тарифах с 1 ГБ
  и меньше стоит добавить файл подкачки на 512 МБ — 1 ГБ — дешёвая страховка на случай
  кратковременного скачка (например, во время `pip install`).
- **2 ГБ свободного места на диске** — под операционную систему, окружение и базу с
  историей, которая растёт медленно.
- **Пропускная способность канала роли не играет** — реальный расход в районе сотен
  мегабайт в месяц.
- **Linux с systemd** для автозапуска; без него бот тоже запустится, просто без
  автоматического перезапуска при падении.

**Выбирайте сервер, который не блокирует Cloudflare.** API gmgn стоит за Cloudflare, и
часть диапазонов бюджетных VPS-провайдеров у неё в чёрных списках — вместо данных
приходит страница проверки браузером вместо JSON, и бот вообще не сможет прочитать
рынок, сколько ключей ни пересоздавайте (подтверждено на практике на **vdsina** —
пересоздание ключа с нуля не помогло). Проверить сервер ещё до установки, ключ gmgn для
этого не нужен:

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://openapi.gmgn.ai/v1/market/rank
```

- **401** — нормально: запрос дошёл до gmgn, тот просто просит ключ, которого пока нет.
  Можно ставить бота.
- **403** или что угодно, кроме числа, — сервер попал под блокировку Cloudflare, нужен
  другой провайдер: новый ключ этого не исправит.

## 📦 Данные и конфиденциальность

Всё лежит в `alerts.db` рядом с кодом — история алертов и настройки, больше ничего. Ни
база, ни какой-либо ключ никогда не попадают в git; секреты хранятся только в
`~/.token-alerts/` с правами доступа только для владельца.

## 🧰 Стек

Python 3.10+ · aiohttp · SQLite (входит в стандартную библиотеку) · официальный

(необязательно) · openssl (разовая генерация ключа) · systemd
